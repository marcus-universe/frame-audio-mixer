What do you want to install?

Frame Audio Mixer runs on the headset. Frame Audio Link is an optional add-on for the PC you stream from.

Looking for the files? All releases on GitHub

Frame Audio Mixer

On the Steam Frame

  1. Turn on Developer Mode

    Steam Settings, then System, then Enable Developer Mode. Konsole only shows up after that.

  2. Open Konsole

    Press + on the bar at the bottom, open the list of programs, then choose Konsole.

  3. Run the installer

    It installs the latest release and checks its checksum before anything is changed.

    curl -fsSL https://frame-audio-mixer.marcus-universe.com/i | sh

Manual download

  • frame-audio-mixer-aarch64.tar.gz

  • SHA256SUMS

Want the extra microphones and outputs on your PC too?

Uninstall

Run this in Konsole on the Frame. It removes Frame Audio Mixer, its background services and its WirePlumber script. Your settings stay in ~/.config/frame-audio-mixer.

curl -fsSL https://frame-audio-mixer.marcus-universe.com/i | sh -s -- --uninstall

Frame Audio Link

On the PC you stream from

Needs Frame Audio Mixer 2.2 or newer on the headset, and wireless streaming to the Steam Frame already working.

  1. Run the installer in PowerShell

    Paste this into a PowerShell window and press Enter.

    irm https://frame-audio-mixer.marcus-universe.com/get-windows | iex

  2. Allow administrator access

    Windows asks once. This creates the eight sound devices. Steam's own Microphone and Speakers stay as they are.

  3. Turn it on in SteamVR

    SteamVR Settings, then Startup / Shutdown, then Choose Startup Overlay Apps, then Frame Audio Link. The dashboard then has an Audio Link tab.

  1. Check that PipeWire runs

    It should say PulseAudio (on PipeWire …). Ubuntu 22.10 or newer, Fedora and Arch work. Ubuntu 22.04 does not.

    pactl info | grep "Server Name"

  2. Run the installer

    Run it as your normal user, without sudo.

    curl -fsSL https://frame-audio-mixer.marcus-universe.com/get-linux | sh

  3. Turn it on in SteamVR

    SteamVR Settings, then Startup / Shutdown, then Choose Startup Overlay Apps, then Frame Audio Link. The dashboard then has an Audio Link tab.

Uninstall

Run this in PowerShell. Windows asks once for administrator access to remove the eight sound devices. The SteamVR entry and the program go too. Your settings stay in %APPDATA%\frame-audio-link.

iex "& { $(irm https://frame-audio-mixer.marcus-universe.com/get-windows) } -Uninstall"

Or double-click uninstall.cmd in the unpacked Windows archive.

Run this as your normal user. It removes the add-on and its SteamVR entry. Your settings stay in ~/.config/frame-audio-link.

curl -fsSL https://frame-audio-mixer.marcus-universe.com/get-linux | sh -s -- --uninstall
