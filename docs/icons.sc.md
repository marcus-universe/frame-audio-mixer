# 图标

Frame Audio Mixer 的 logo 以 SVG 格式放在 `assets/logo/`，有蓝色和粉色两种。`assets/icons/` 存放面板和仪表盘使用的 PNG。录制、停止和播放是绘制的形状。面板里的其他字形是嵌入的路径，不会在运行时下载：

| [famicons:mic-off](https://icon-sets.iconify.design/famicons/mic-off/) | famicons | Family | MIT |
