# アイコン

Frame Audio Mixer のロゴは、`assets/logo/` に SVG で入っています。青とピンクがあります。`assets/icons/` には、パネルとダッシュボードが使う PNG があります。録音、停止、再生は描いた形です。ほかのパネルの字形は埋め込んだパスで、実行時には取得しません:
